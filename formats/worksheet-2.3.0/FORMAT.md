# 交互数据处理台

ExperimentWorksheet 描述一个开放实验的可填写界面，依赖本实验已保存的草稿版本。每个子实验保留独立测量条件、原件页、输入与计算。读数和选区由实验库独立保存，重算无需模型。作者依 authoring.md 编写，运行时验证变量、公式、依赖和原件引用。

草稿格式 physics.draft 的 measurement_methods 按方法保存必交量、观测量和所据原式。每种方法分别记下参考方向、仪器或试样端点、单位、取数条件和可用测法。derived_from 记录计算观测的来源，录入单位与计算单位由宿主分别声明。

生成顺序为读取课程原件及所需原图、保存工作草稿、按方法分别编制可执行页、在宿主核对单位与依赖、保存包含可执行页的草稿修订、从该修订建立数据台。编页时同时读取本方法原件并填写依据，正常生成至此发布。用户提出新分析要求时接续草稿和对应页，沿用已有读数与版本历史。

equations 保存该方法采用的原式及适用条件，阶段要点说明知识、选材和诠释安排。正式页的数学展示由其计算表达式生成，结果说明解释物理含义和使用条件。定性目标由宿主建立文字记录栏。历史包保留其来源复读契约供原有记录追溯。
