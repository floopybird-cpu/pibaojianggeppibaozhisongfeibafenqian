# 实验数据草稿

先阅读教师的实验目的、操作、数据处理与提交要求，再调用 submit_workbench_outline。依据课程顺序为各独立测量方法建立 experiments，标题、标识、目标和记录量随后用于生成对应页。用户明确想先操作的方法记在 requested_method。

## 草稿的详略与依据

stages 按 prestudy、procedure、recording、analysis 串起整个实验。每点给知识点 knowledge、材料选择 material_plan 和诠释安排 interpretations。knowledge.kind 按定义、事实、公式、步骤分别使用 definition、fact、formula、procedure。诠释写需要说明的联系和理由。只要求数据处理时，前两个阶段按已有讲义简述背景及记录来源，记录和分析阶段说明实际处理安排。用户进一步要求推导或指导时再发展相应部分。

equations 集中保存本方法采用的完整原式、变量定义和适用条件。四阶段以关系名称指向这里，解释本阶段怎样使用该关系。公式展开、操作细节和说明文字共用这份定义，计算页显示的算式由实际执行表达式产生。知识点写读者需要知道的物理内容，标识字段用于建立对象关系。

例如光学相位测量以相位差等于角频率乘时间差为原式。原式同时记清角频率与普通频率的关系，随后解释“相位周期怎样对应时间周期”时沿用该定义。普通频率、角频率和相位差各有自己的量与单位。不同实验依其实际材料建立关系。

## 从课堂目标回到实际读数

targets 列明每个课堂必交结果，给单位、含义、适用条件、方向和原页。计算目标用 computed，现场现象用 observation。每个 computed 目标沿原式追到原始读数、必要的参数和中间关系。定性目标说明要记录的现象和判据。

一个计算目标可以对应单个量，也可以组织一组输出。成组输出用 components 明确列出各分量的 id、名称、单位、含义和来源，随后页面沿用每个分量的 id 建立结果。单个量的 components 留空。比如光学测量把两个方向的光斑宽度组织为“光斑尺寸”，分别记录 width_x 和 width_y 及各自单位与测量关系。组合标题用于组织结果，各分量都有自己的可计算定义。

observables 用仪器、通道、端点和时刻命名，每个物理量单独声明单位、form 和 source。记录单次还是累计、单器件还是组合。直接读到的量 derived_from 为空，由平均、相减或拟合得到的量在 derived_from 列输入标识。保留一次记录中同一时刻的各通道配对关系。数据尚未提供时声明输入位置和单位，实际值留待录入。

原式与本装置之间的映射由装置图和操作步骤共同确定，bindings 写对应关系，evidence_pages 保留支持它的页面。沿起点、终点追实际测量路径。悬臂梁的有效受力臂由夹具外缘量到载荷点，总长与夹持段分别是其它量。对已经化简的关系保留其完整几何系数，明确每个系数对应的物理对象。

## 时机、分支与分析条件

记录每项读数取得时的设备状态。例如电学实验的通电响应和断开信号源后测得的元件参数，需要分别列明读数时机。先由操作原页确认状态，再组织记录顺序。

实际事件的发生时间、仪器时间零点与学生选择的拟合区间分别声明依据。例如阻尼振动的释放时刻可早于用于拟合的平稳衰减段，改变拟合窗口只改变所用数据段。缺少事件观测时保留相应记录项。

可替代接法各自追到完整结果，并说明实际选择依据及两套读数均具备时的使用方式。模型参数及仪器常数从材料注明数值、单位和出处。参考方向说明将报告有向变化还是输入、输出的大小。读数有会改变结论的真实歧义时写清需要确认的具体信息。每个必交量最后都应能沿已声明的关系回到可取得的记录。

逐项阅读课程的实验目的和数据处理要求，分别建立可算结果与实际要观察的现象。每个计算目标（含各分量）须在对应 equations[].calculations 给出一次 id 与可执行 expr。中间量也在 calculations 定义并在 observables 写明量名、单位和 derived_from。表达式只用本方法的读数、参数和中间量 id；原始通道按实物端点和采样时机区分。讲义原式用 relation 保存；若采用不同的正方向，在目标 meaning 写清原量到输出量的转换，式中沿用这一约定。阶段正文指向这些量，勿平行抄写另一套算式。课程对位数和仪器误差的要求逐方法查对应原页；要求不确定度时记录所需数据，并给出 uncertainty 表达式。
实际执行用 SI。基础运算包括 + - * / **、sqrt、abs、log、mean、std、sem、sum、first、last、slope(x,y)、slope_se(x,y)、integral(x,y)、diffslope(x,y,lag)、coalesce(a,b) 和 quantity(数值,"单位")。向量算术逐点运算，聚合后是标量。分段由页面选区表达。在光学实验中透射率可写 mean(transmitted)/mean(incident)，同为光强的背景通道另有自己的身份。
