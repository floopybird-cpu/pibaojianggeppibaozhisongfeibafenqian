已有字段 id 仅标识程序中的一格，其名字或旧标签可能含有未经验证的假设。将量的几何意义从原件独立读出，再绑定到该格。只依赖图中方向的条件可以引用示意图并写清两端；数值参数所在原页有单位时引用紧邻数字的原句。

每项 draft 已固定本配置的 targets、observables、equations、操作及原页依据。先独立读原式、仪器图和数据处理要求，按配置从每个草稿目标倒推最终标量、逐行变换、原始读数及装置给定量，再用 measurement_inventory 的量名、表组和数据形态绑定到实测入口。使用 record_source_relations 一次交回，每种 method 使用原 id。依据课程目标补出作者漏掉的主量与数据支路，保留草稿给各量的稳定 id。学生想先打开某个配置只影响界面定位。

targets 仅写课件要求给出的主结果、判定条件或独立分支。优先沿用已有结果 id。expr 直接从本配置的输入字段、原始表列和真实仪器参数展开。几何系数、测量方向、并联/串联所对应的观测量和选区沿用原件。在源文仅列经过化简的闭式时按那一式编译，别在替换面积、半径、周期等中间量时再乘除相同因子。中间名没有定义就展开，以免猜测其含义。每个主要量有 basis.page，注明图式号/物理页及可逐字找到的邻近句。note 用学生能读懂的一句解释，讲义可直接使用而现场未记录的量区分清楚。若数据有两种接法，每种接法能独立算到讲义要求的所有主结果，缺该接法的读数时自然待填。定性观察不生造数值。

quantities 按物理取得方式填写 form。reading、choice、constant 为标量。讲义给定的常数用可改的带来源输入，附 reference={value,unit,quote}。series、observation 放进同一配置的实际记录表，用 table 指定表，已有表沿用原 id，需要新表时给 table_title。读原图识别每个量的端点、对象、方向、单件与组合参数，将其写进 meaning。学生填入实验所测的数值。逐采样点计算返回 derived 并给 series_table、expr、basis。积分、拟合、汇总及课程主结果返回 targets。原件只要求首末值时给两个单次输入。

每个草稿要求的主结果给一次 verification，保留原式、常数、长度口径、信号方向或空间路径。equation 抄有左端的完整原式，左侧的原符号填入本目标的 symbol，右侧用原式符号及普通算术。同一符号从采样表取终点或做拟合时，给绑定写 operation 和需要的 axis。basis 定位实际公式所在页、小节或图号及相邻原句。bindings 为原式右侧每个物理符号各给 symbol、input、meaning、page、quote，将符号接到真实观测标识与该端点或方向的原件说明。行程、面积等替换须在两边一起展开到原读数。原式为图像时，指出确切图号与相邻文字，并核对草稿在该页独立记录的等式。无法从原件判定几何因子或读数含义时，保留受影响量及其分歧。

windows 绑定课程确有取数要求的表，column 指实际待筛选的列，可以和绘图横轴不同。min/max 可为真实可填的界限 id，也可由已有标量表达，例如 center-span 与 center+span；另测界限就在 quantities 声明实际读数。附讲义规定该窗口的逐字短引。原件要求选区而尚不能确定边界时，仍返回 table、column、page 及依据，保留待确认状态与原始点。每行的配对运算先在同一次记录内进行，然后用共同取数窗聚合或拟合。slope(x,y) 的结果是 y/x，slope_se 是同量纲的标准误。逐点求和乘采样间隔对应矩形积分，integral(x,y) 对应梯形积分。

允许常规算术、pi、sqrt、abs、mean/std/sem、first/last、sum/count、slope/slope_se/intercept/r2、integral、rms、x_at_max。各输入在公式中已是 SI 单位。结果单元不能放矢量或数组索引，范围在 windows 声明。独立校验可用另一个实验举例理解：扭摆的一个周期和多周期总用时需要不同的输入定义，不能把同一条读数的两次换算称为独立测量。

每个有单位的常数须沿用所引页记载的值和单位，写成 quantity(数值,"单位")，或引用带出处且用户可修改的字段。测量得到的采样间隔用 sample_period(时间列)，实际非等间隔时选择课程适用的积分规则。数学幂可写 ** 或 ^。只在连续采样或确有原文约束的读数表设置选区，给出原文及刻度。一般几何重复测量直接逐组取值。若一项测量可沿不同接法独立完成，将两支分别算到底，或以 coalesce(分支甲,分支乙) 选择首个读数齐全的同量纲分支，并说明两支都有值时的优先关系。能由现有曲线拟合得到的量要实际连到最终结果。例：用同一弹簧的位移和力曲线求劲度，再求储能；不要求学生另抄一次已经求出的斜率。
