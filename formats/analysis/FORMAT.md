# 分析程序与运行结果包

版本 1.1.5，数据版本 1，宿主接口 1。用于当前实验的完整现场 Python 程序与运行回收，不存全局教材知识。

先在数据关联入口确认 CSV/TSV、XLSX 表或温度采集 DAT 段的每列物理量／通道及单位。多表／多段必须明确选取，原件不重写。使用“编写分析程序”让同一 Agent 现场构建分析步骤和完整代码。代码、输入、参数、environment.lock 和 formula-map.json 固定保存。

methods.json 声明七类基础分析：带截距最小二乘与残差、稳态窗口、目标温度附近局部冷却导数、稳态热平衡与散热面积修正、准稳态平行升温与热流、同步电功和条件性制冷 COP、重复读数与敏感性。每项均列输入单位、步骤、条件与拒绝情形；程序的 method_ids 必须选自该清单。包内 reference.py 是可选纯数值参考核，复制为只读输入 analysis_methods.py，仅由受限分析进程按需使用；不能代替 Agent 针对本次任务构建完整代码。

稳态圆盘参考式采用整个样品截面的近似一维热流，须先核对有效接触。样品大于盘、局部接触或明显扩散热流时，不能仅代入整个样品直径；参考核拒绝已知的样品直径大于盘情形，不擅自换成盘面积得出貌似确定的结果。其他接触条件仍由本次模型和操作记录判断，不由一个直径检查证明全部成立。

程序入口为 analysis.py；argv[1] 是 inputs.json（datasets 数组，每项有 id、mapping、rows）；argv[2] 是 parameters.json；argv[3] 是输出目录。输出 result.json，并按需输出 intermediate.csv、plot.png。显示公式不能直接当计算表达式执行。公式映射记录步骤、固定公式引用、代码行、输入列和单位。

build 的 analysis_inputs 入口把已确认的整表／采集段完整冻结在程序交付的 inputs.json，而非只给 dataset_ids；程序脱离数据库也可照固定接口复跑。apply 的 runtime_environment 入口采用宿主实际探测的独立 Python 和已安装依赖版本，覆盖模型自报的泛称，生成环境锁定文件。模型不能借该字段安装依赖或更换执行器。

WindowsSandbox 用每次运行的独立 AppContainer、零网络能力、只读运行组件／输入、仅暂存输出可写、无继承句柄和最小环境；Job Object 负责整棵进程树的生命周期。默认不设人为运行时长、内存和输出数量／大小配额，用户可在设置中选用时长、内存与输出大小上限，取消会结束整次运行。不可用时明确失败，不使用宿主令牌运行代码。已保存输入不改写；所有层级的普通输出文件通过宿主回收并经包提交，成功退出不等于物理正确。

内置 Python 3.13.16、NumPy 2.3.4、Matplotlib 3.10.7；完整传递依赖版本见 requirements.lock。依赖不在运行时联网安装。保留 stdout/stderr、退出码、中间值、图和参数；取消／超时杀死作业树，回收部分产物并标状态。

schema.json 和 program.json 定义本包的真实读写程序，read/query 给出语义视图，apply 检查步骤与引用并只编译语法而不在宿主执行分析内容，build 固定程序接口文件，finish 拒绝缺失交付。程序使用有界声明式指令，不能注入 UI、执行任意包代码或访问权威库。用户／Agent 的现场 Python 仅由上述 AppContainer 实际执行，再由宿主回收并走本包入口登记。

planUpgrade 给出固定目标、人改与迁移影响，upgrade 可保留内容形成新修订；结构与新事实不会静默补齐。完整迁移、人改导回、第二机封装按 PH-M3 验收，不以最小升级测试代替。不得把固定演示代码说成实时模型编程。
