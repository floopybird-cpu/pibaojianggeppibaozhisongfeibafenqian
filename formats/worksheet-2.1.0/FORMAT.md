# 交互数据处理台

ExperimentWorksheet 描述一个开放实验的可填写界面，依赖本实验已保存的草稿版本。每个子实验保留独立测量条件、原件页、输入与计算。读数和选区由实验库独立保存，重算无需模型。作者依 authoring.md 编写，运行时验证变量、公式、依赖和原件引用。

草稿格式 physics.draft 1.4.0 的 measurement_methods 按方法保存必交量、观测量和所据原式。每种方法分别记下参考方向、仪器或试样端点、单位、取数条件和可用测法。derived_from 记录计算观测的来源，录入单位与计算单位由宿主分别声明。来源核对读取完整实际计算图，把有依据的改动同步写回方法方案及受影响的知识与诠释点，然后保存最终可执行修订。数据台各页从该固定修订投影。定性任务有独立现象记录栏，改用分析法时先接续草稿再更新相应页。
