# 范例：区分知识和诠释，不按某个验收实验背答案

## 单摆周期：同一个点里的不同工作

知识点可列：摆长是支点到摆球质心的有效长度（定义）；在小角度等相应近似下，周期关系为 $T=2\pi\sqrt{\ell/g}$（公式与条件）；记录若干完整周期的总时间及所计周期数（操作知识，次数由实际设计决定）。这几条本身不是三项诠释。

选材安排：本实验讲义负责装置、摆长口径和计时方法；若用户需要理解周期关系，再选择教材中小振动或单摆推导。只要求处理计时数据时，讲义里的关系和条件足够衔接，不先补完整振动学。

诠释要点可以是2项：
1. 为什么可近似为简谐振动：从切向回复作用和小角度近似连接到运动方程，说明近似做在什么地方；不只复述“小角度适用”。
2. 为什么计多个周期：解释总时间与周期的关系及计时分辨能力的影响，也指出累计计数和起止判据仍须一致；不把“多测几次”当作解释。

数据分析直接进入时，预习阶段写“按讲义说明周期关系、摆长与计时口径”即可简要衔接，分析阶段再安排所需的拟合或重复测量处理。用户后来要原理讲透，才先把第1项诠释扩入草稿，再写推导。

结构上，“求重力加速度”要接到有效摆长与周期的定义，再接到长度、总时间与周期数的记录，最后接处理方法和结果解释。若摆长定义没有讲清，后面计算可以数值无误却针对错误对象；这是概念到读数的组织缺口，不能只修最后一句结论。若讲义简写为“周期与振幅无关”，应回到所用近似辨明范围，再决定正文如何限定，不能把简写扩成所有振幅下的普遍命题。

## 电阻测量：条件和解释的分工

知识点可列欧姆关系、端电压和电流的定义、测量范围等实际资料中的内容。诠释可以讨论：为什么要说明电阻所处条件；多组数据中的斜率代表什么；截距或变化趋势出现时应区分数据现象与机制诊断。记录到的曲线变化不能直接升级成已经确认某种原因。

选材时先用实验讲义确认实际接法和仪器读数；只有解释确有需要才补相应教材。草稿写出这些选择与用途，正式引用随后核实。不要凭范例给未知仪器编参数，也不要把本范例的诠释问题机械加入每个实验。
