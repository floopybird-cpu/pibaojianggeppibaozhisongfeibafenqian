# 学习文档与实验单包

版本 1.0.4，数据版本 1，宿主接口 1。固定章节、段落、数学、符号、表格、图像、代码、交叉引用与旁侧来源模型。

在一个实验里保存背景、目标、时间和选用教材，使用包声明的短预习、深入讲义、实验计划按钮。同一 Agent 读取本课来源并生成内容。没有 API 时可显式选择“按保存知识编排”短版／深版，界面和文档标明未调用模型。深版必须有 math_basis 与 derivation，且已有数学基础和 MathUse 支撑。

实验计划逐个目标量给出公式、直接读数、单位、时机、条件、仪器及精度。步骤有理由、条件、完成判据和目标映射。附录 records、errors、instruments、reading 分别处理记录、误差、按钮细节及拓展阅读，保留直接定位与 Word 内链接。未知精度和操作明确待确认，不编造本课仪器。

schema.json 定义文档块、目标量与步骤结构，program.json 是实际执行的 format-pipeline/1 程序：apply 检查条件、引用、目标覆盖及附录；build 调用共享有界生成器，finish 核对必需资产。生成器仅获得冻结的内容、知识／来源快照、允许图像和本次暂存输出，不获得数据库连接、密钥或可执行的包脚本。

生成 document.docx、document.pdf、document.md、preview.html、sources.json 后由宿主网关提交。PDF 使用离线的通用 Word 阅读排版，公式由 MathML 排成矢量图，文本可选择；无需用户安装 Office、浏览器或 TeX。原生界面默认显示完整 PDF；内容与出处仍可逐块查看。每次生成或修订，宿主自动复制完整可阅读文件到独立的“生成产物/实验/文稿类型”文件夹；文稿以 Word/PDF 交付，Markdown/HTML 仅作内部表示。外部副本删除不影响内部记录，手改文件不被静默覆盖。Word 数学使用原生 OMML，支持分式、上下标、根式、上下限、矩阵和重音；未知命令或不支持的构造明确报错且旧版不变。原页图可带出处插入，图像和文本普通阅读保持可用；必须文件缺失不能完成。

template.json 控制 A4、字体、附录分页和交付，开发者可直接改包并发布新版本，学生无须写模板。附录有各自 ID、书签和链接，可直接定位，并不强制每个小附录占满一页。发布／数据／接口版本独立，完整包按摘要缓存；同版本不可改写。planUpgrade 固定目标、基线和人改提示；upgrade 执行包内有限迁移、保留内容、重生成新修订，失败保持旧版。新增事实与结构迁移不在样式操作中补造。缺包时先找固定缓存，仍缺则普通看原交付，不能提交新版。完整人改导回、迁移中断恢复与第二机属于 PH-M3。

模板1.0.1将表头与首行保持在同一页，并将实验目标固定引用的唯一公式自动生成为原生Word公式对象，免于模型重复抄写。旧包与旧资产保留，升级只重生成排版，不补造内容。

PDF 使用 SVG 1.1 独立字形路径，避免渲染器不支持 SVG 2 symbol/use 时丢失字形；长公式链在关系符处换行。Word 保留可编辑 OMML。此版只修显示兼容性，不改科学内容。
