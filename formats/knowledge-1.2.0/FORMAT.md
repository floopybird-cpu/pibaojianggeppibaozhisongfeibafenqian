# 物理与数学知识包

版本 1.1.0，数据版本 1，宿主接口 1。用于全局 SciencePoint、MathFoundation、Formula、MathUse 和具名关系；不存实验读数。

在资料库选择材料，打开原页核对，再点击本包声明的“蒸馏所选资料”。有模型配置时先检索已有对象和目录，逐条保存出处；无模型可在“核对并录入知识”入口填写同一格式。只有声光力电热五个顶层目录，细目录按材料创建；数学基础是单独类型。

每条断言、公式和条件使用稳定 SourceAnchor。公式说明量、单位、维度、形状、近似与核对状态。MathUse 给出数学符号到物理量的映射、假设和步骤。关系类型为先修、推出、适用于、测量、误差来源，标明证据或推断。跨源归并保留差异，不覆盖条件冲突。

schema.json 定义领域结构，program.json 是 format-pipeline/1 的实际可执行程序，包含 read/query/apply/build/finish/planUpgrade/upgrade。程序同时声明归并身份字段、集合并集和条件冲突策略；宿主不再为每个包写死这些规则。知识没有二进制必需输出。宿主仅提供结构校验、引用校验、有限规范化、视图、生成与样式迁移等有界指令，不执行包中任意 Python/JS。

planUpgrade 返回固定目标、基线、人改提示和包内迁移规则；upgrade 保留内容与旧修订。缺新增事实或不支持的结构迁移明确失败，不能猜测补齐。完整的人改导回、长期迁移恢复和第二机验收仍属 PH-M3，不能以这条最小路径通过代替。

开发者直接修改包目录中的结构、程序、说明和图标，发布时更改版本，不修改 React 或宿主领域代码。发布后不可原地修改同版本；宿主将完整包缓存为不可变摘要，旧成果优先找固定缓存。找不到固定字节时只读。按钮由元数据自动生成；依赖、入口或指令不兼容时拒绝激活，图标缺失用回退图标。普通原文／原页阅读始终保留。

## 知识检索说明

助手阅读原页后为每个新增条目另写一句短说明和主题词，中英文术语使用原文对应词。出处写明原文件、文件页序和该页支持的知识。先检索说明，再打开命中条目的固定修订和实际原页核对公式、条件与图示。一次没有命中可以返回空结果。

## 分级主题目录

主题按学习问题组织。助手可以建立多级目录，将核心知识、互补细节和同义复述区分保存。共用出处或相似术语不能证明两项结论相同。目录整理只读取已存短说明与章节；新增材料可复用已有知识并追加原页。
